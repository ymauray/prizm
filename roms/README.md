# ROM du ZX Spectrum

| Fichier | Contenu |
|---|---|
| `48.rom` | ROM du ZX Spectrum 48K |
| `128-0.rom` | ROM 0 du Spectrum 128K : éditeur, menu et BASIC 128 |
| `128-1.rom` | ROM 1 du Spectrum 128K : BASIC 48K (proche de `48.rom`) |
