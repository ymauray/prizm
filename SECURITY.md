# Politique de sécurité

## Versions supportées

Prizm est activement maintenu sur la branche principale `main` ainsi que sur la version stable la plus récente.

| Version | Supportée |
| --- | --- |
| `main` / dernière version | :white_check_mark: |
| Anciennes versions | :x: |

## Signaler une vulnérabilité

La sécurité des utilisateurs et l'intégrité du code sont prises au sérieux. Si vous découvrez une faille de sécurité ou une vulnérabilité dans Prizm :

1. **Ne pas ouvrir d'issue publique.**
2. Utilisez la fonctionnalité de **signalement privé de vulnérabilité** de GitHub :
   - Rendez-vous sur l'onglet [Security](https://github.com/ymauray/prizm/security) du dépôt.
   - Cliquez sur **Report a vulnerability** pour soumettre un rapport confidentiel.
3. Décrivez précisément le problème, les étapes permettant de le reproduire, ainsi que son impact potentiel.

Nous examinerons votre signalement dans les plus brefs délais et travaillerons à la publication d'un correctif avant toute divulgation publique.
